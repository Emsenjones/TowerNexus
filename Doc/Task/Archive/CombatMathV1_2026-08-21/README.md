# CombatMathV1 Task Archive

Archived on 2026-08-21 before the CombatMathV2 damage-formula and balance
restart.

The Task documents in this directory are preserved historical evidence. They
retain the accepted and in-progress contracts, values, test interpretations,
and Stage1 calibration state that existed at the archive boundary. They are not
the active source for CombatMathV2 implementation or balance values.

Associated Recorder JSON remains in `Doc/GamePlayRecord/` so existing report
paths and evidence are not duplicated or rewritten.

The active sequence begins at `Doc/Task/README.md`.
