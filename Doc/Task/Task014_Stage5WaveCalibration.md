# Task014 - Stage5 Wave Calibration

Status: Planned

Depends on: Accepted Task013 Stage4 Wave Calibration

Blocks: Task015, Task016, and Task017

## 1. Goal

Calibrate Stage5 as the first Stage that requires one coherent Elemental Core
without requiring two-source Elemental cooperation.

## 2. Fixed Design Intent

- all four TowerFamilies and Elemental content available;
- ten-Draft candidate budget;
- one L3 Core with one Basic, one Behaviour, and one Elemental Upgrade;
- four L1 Supports representing all four families;
- Anti-pattern averages investment without completing an Elemental Core.

## 3. Stage Composition And Fixed Build Fixtures

- Derive exactly ten Drafts from five Tower placements, two Core Level Ups, and
  three Core Upgrade applications.
- Author the exact cumulative four-family Tower pool and all Stage-unlocked
  Basic, Behaviour, and Elemental UpgradeDefinitions. Prove continuous Level 3
  reachability for every family permitted to reach it.
- Select one reproducible Core family, ElementType, exact Reference package,
  coherent alternative, averaged-investment Anti-pattern, and legal placement
  assumptions.
- Author one ten-step naturally eligible Fixed Draft sequence for every required
  Build, preserving the Tower-only Initial step and normal Draft, Pending,
  placement, Level Up, Upgrade, Elemental exclusivity, and consumption rules.

Fixed sequences prove that a selected Elemental Build works; they do not prove
how frequently natural offers make it available. Task017 owns that evidence.

## 4. Stage Calibration And Monster Authoring

Author nine positive Player Progress Requirements. Their sum owns the final-
Draft resolution node; the total Monster budget must leave a meaningful
completed-Elemental-Core test.

Reuse fixed-speed Profiles accepted by Task010-Task013 whenever possible. Add a
new Profile only when none can express Stage5's Elemental application, stack,
and late-pressure needs. A new Profile records explicit HP with
`MoveSpeed = 0.25`; standard Waves retain `SpawnInterval = 2.5s`. Accepted
upstream Profiles remain immutable unless their introducing Stage and affected
dependents are reopened.

Record the complete `MonsterWaveConfig` table and jointly calibrate Progress,
Profile order and Count, any new HP, `WaveDelay`, Player Health, exact packages,
and placement.

## 5. Acceptance

- a single Elemental Core has meaningful application and stack value;
- Reference does not require Overload from a second source;
- non-Elemental support contribution remains visible;
- Reference and coherent alternative clear within the accepted margin;
- averaged investment that never reaches an Elemental Core does not reliably
  clear;
- all ten Drafts occur at reviewed pressure nodes with meaningful post-final-
  Draft Elemental-Core combat;
- exact Stage pools, Level 3 reachability, legal Build fixtures, and Fixed
  sequences are accepted inside this Task;
- every Profile is identified as reused or first accepted here and the accepted
  Wave table matches the authored `MonsterWaveConfig`;
- FixedBuff and TowerScaled attribution remain distinct in the Recorder.

All Build comparisons use Fixed Draft sequences. Natural Elemental-offer
availability and player-choice interpretation belong to Task017.
